## 🚀 Quick Start (Choose Your Platform)

### Option 1️⃣: Start with Web (2 minutes)

```bash
cd web
npm install
npm run dev
```

**Result**: Your landing page at http://localhost:3000

### Option 2️⃣: Start with Mobile (5 minutes)

```bash
npm install
npm start
npm run android  # or npm run ios
```

**Result**: Landing page on iOS/Android emulator

### Option 3️⃣: Run Both Together

```bash
# Terminal 1: Web
cd web && npm install && npm run dev

# Terminal 2: Mobile bundler
npm install && npm start

# Terminal 3: Mobile app
npm run android
```

**Result**: Web + Mobile running simultaneously
